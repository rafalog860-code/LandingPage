# A demo fica fora do indice por DOIS motivos, e o segundo e' o forte:
#  1. e' uma barbearia de exemplo - conteudo de teste competindo
#     na busca com a landing so atrapalha;
#  2. calendario e' armadilha de rastreamento: cada dia, cada profissional e cada
#     servico vira uma URL nova, e o robo entra num numero praticamente infinito de
#     paginas rasas. Isso gasta o orcamento de rastreamento do dominio inteiro.
# O link continua funcionando normalmente para quem clica - o que muda e' so o
# buscador nao listar. Se um dia a demo virar peca de conteudo, reverter esta linha.
Disallow: /demo/

# As imagens dos posts do Instagram (17/08/2026). Elas moram aqui porque a API da
# Meta busca a imagem por URL publica, a partir do servidor dela - caminho de
# arquivo local nao funciona. Mas sao MATERIAL DE ORIGEM, nao conteudo do site:
# indexadas, competiriam na busca com as paginas reais e diluiriam justamente o
# que a gente quer que apareca.
Disallow: /midia/
